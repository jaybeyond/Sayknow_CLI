# Notice

`verification-receipts` is an independent re-implementation of the contracts of the
`verification-receipts` plugin from [`jjongguet/gjc-plugin`](https://github.com/jjongguet/gjc-plugin)
(MIT License, Copyright (c) 2026 jjongguet): the delegation verification gate, immutable
freshness-bound test receipts, and a bounded recheck loop. No source text was copied; the
behavior contracts, tool names and closed vocabularies follow that design.

The upstream license text is kept in [`LICENSE.gjc-plugin`](LICENSE.gjc-plugin). Every TypeScript
file in this bundle carries a header that names the upstream project and license.
